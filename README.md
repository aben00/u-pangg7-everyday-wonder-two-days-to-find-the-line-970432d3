A single sentence, at most 200 characters, that makes a small everyday moment strange and new. An AI judge compares entries two at a time on freshness of angle, whether the surprise lands in a single read, and whether it stays grounded in something real.

## Run it

```sh
node main.ts
```

It writes the entry sentence to `/output/entry.txt`, self-checks the gate (one line, 1–200 characters, no control characters, no edge whitespace), reads it back and verifies it byte-for-byte.
